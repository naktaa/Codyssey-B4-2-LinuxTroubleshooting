## Constraints

- Linux 머신 안에서 일반 사용자로 실행한다. 머신의 아키텍처 확인 결과에 따라 제공 바이너리를 선택하며 macOS 호스트 정보만으로 선택하지 않는다.
- AGENT_HOME 필수, AGENT_PORT=15034, AGENT_UPLOAD_DIR=$AGENT_HOME/upload_files 디렉터리 존재, AGENT_KEY_PATH=$AGENT_HOME/api_keys 경로 존재, AGENT_LOG_DIR 존재 및 쓰기 권한을 충족한다.
- MEMORY_LIMIT는 정수 50~512 MB, CPU_MAX_OCCUPY는 정수 10~100%, MULTI_THREAD_ENABLE은 true/false(1/0, yes/no 허용)다. 초기값과 의미는 구현 계획에 설명하며 장애 유발 설정을 관측 전 확정된 정답처럼 취급하지 않는다.
- $AGENT_HOME/api_keys/secret.key에 원문 지정 공개 시험용 값을 사용한다. 실제 credential은 사용·기록하지 않는다.
- 0.0.0.0:15034 바인딩 조건을 확인한다. 호스트 공개 설정이나 방화벽 변경을 임의로 추가하지 않는다.
- Bash와 Linux 표준 도구를 우선한다. Docker, 추가 프레임워크, 전역 셸 설정 변경, 자동 장애 실험 체계를 추가하지 않는다.
- 기존 바이너리·사용자 파일·실행별 증거를 보존한다. 로그 재수집이 이전 증거를 덮어쓰지 않도록 단순한 방식을 제안한다.
- 실제 실행·테스트는 사용자가 담당한다. AI는 정적 self-check와 실행 안내를 제공한다.
